# Security policy

Until 1.0.0 is released, the project is under development and has no supported
stable version. After release, security fixes target the latest stable version;
upgrade guidance will accompany advisories.

Do not disclose vulnerabilities in public issues. Once source publication is
approved, enable GitHub private vulnerability reporting and use the repository's
Security tab to submit a private report. If that option is unavailable, contact
the maintainer through the public GitHub profile and arrange a private channel
before sending details. Do not send secrets in public comments.

Provide affected versions, a minimal reproducer and impact. Maintainers will
acknowledge and coordinate a fix/disclosure; no response-time guarantee is made
before the project has a staffed support policy.
